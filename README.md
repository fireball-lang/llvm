# Fireball LLVM build

This repository builds a minimal set of LLVM tools and runtime libraries required by the [Fireball](https://github.com/firball-lang/fireball) compiler.

## Platforms
- Windows (x64)
- Linux (x64)
- MacOS (aarch64)

## Tools
- llc
- llvm-as
- lld

## Runtime
- compiler-rt
- libunwind
